01 / 可视化编辑器

做一个会移动的小球

这个练习只用编辑器操作：创建圆形 → 设置两个位置 → 播放。完成后你就理解了场景、对象和时间线的关系。

  1. 01

    打开空白项目

    点击顶部的「新建」。左侧是对象图层，中间是画布和时间线，右侧是检查器。此时画布为空是正常的。

  2. 02

    添加圆形

    在左侧「对象图层」→「＋ 添加」选择「圆形」。新圆形会被选中；你可以拖动画布上的圆，或在右侧直接修改 X、Y 位置和颜色。

  3. 03

    放置起点关键帧

    保持圆形选中。在中间时间线把动画属性选为「X 位置」，播放进度拖到 0.00 s，点击「＋ 关键帧」。时间线上会出现一枚菱形。

  4. 04

    放置终点关键帧

    把进度拖到 2.00 s，再点一次「＋ 关键帧」。在新关键帧右侧的数值框输入 900 并按 Enter。现在点击画布下方的播放按钮「▶」，小球会向右移动。

    没动起来？检查同一条 X 位置轨道上是否有两个不同时间、不同数值的关键帧。也可以先把两个关键帧的值直接改成 100 和 900。

02 / 交互

让观众自己调参数

关键帧负责“随时间变化”；参数负责“由观众控制”。两者可以用在不同属性上。

＋

添加参数

右侧「场景参数」标题旁点 ＋。第一个参数的 ID 是 p1，默认范围 0–10。展开「参数定义」可改名称、范围、默认值和单位。

ƒ

绑定对象

选中圆形，在右侧「时间表达式」的 Y = 输入框填入 100 + p1 * 40，按 Enter。拖动右侧参数滑块，小球会随之上下移动。

表达式里能写什么？t 表示播放秒数，p1 是参数 ID，x 用于函数曲线的横坐标。支持 + - * / ^、括号、sin、cos、sqrt 等常用函数；不能输入任意 JavaScript。
03 / 现成内容

先改模板，再做自己的作品

编辑器左侧「快速开始」提供三个能直接播放、修改、导出的示例。切换模板会替换当前项目，请先保存自己的改动。

∿

正弦函数

播放时观察运动点与图像。在右侧调「振幅」和「频率」，看看曲线和读数如何同步变化。

↗

抛体运动

拖动「初速度」等参数，观察轨迹、位置和速度。示例使用忽略空气阻力的理想模型。

⌕

二分查找

用播放进度逐步查看比较位置、左右边界和最后找到的目标。

要自己画函数图像：先在「对象图层」添加「坐标系」，再添加「函数曲线」。选中曲线后，在检查器的「函数 y = f(x)」里输入如 sin(x)。

04 / 完成作品

保存项目，或者导出画面

“保存项目”和“导出”用途不同：前者用于下次继续编辑，后者用于课件、文章和视频。

保存项目

顶部点击「保存项目」，下载 .cmanim 文件。下次点「打开」选这个文件，继续修改对象、关键帧和参数。

当前帧 PNG

将进度拖到想要的时刻，右侧「导出作品」点「当前帧 PNG」。适合插入 PPT 或文章。

视频 / 逐帧 ZIP

在支持录制的浏览器中点「视频 WebM」或「视频 MP4」；按钮不可用时选「逐帧 ZIP」。首版没有音轨，逐帧 ZIP 最多 360 帧。

05 / 编程式 SDK

在网页里嵌入动画

如果你会写前端代码，可以直接创建项目数据并挂载播放器。SDK 与编辑器使用同一格式；先在编辑器做作品，再用 SDK 加载也可以。

TypeScript · 最小示例打开可运行示例 ↗
import 'canvas-manim/style.css'
import { createBlankProject, mountPlayer } from 'canvas-manim'

const project = createBlankProject()
const scene = project.scenes[0]
scene.nodes.push({
  id: 'ball', type: 'circle', name: '小球',
  x: 100, y: 150, radius: 24, fill: '#5eead4',
})
scene.tracks.push({
  nodeId: 'ball', property: 'x',
  keyframes: [
    { time: 0, value: 100 },
    { time: 2, value: 600, easing: 'easeInOut' },
  ],
})

const player = mountPlayer(document.querySelector('#stage')!, project)
player.play()
// 页面卸载时调用 player.destroy()

工程内开发可以参照 examples/sdk-demo.html；库构建产物在 dist-lib/。项目文件只保存数据，不保存任意 JavaScript 回调。

遇到问题？

常见问题

我点了播放，但画面没有变化？

静态对象不会自动动。先选中对象，为同一个属性添加两个不同时间、不同值的关键帧；或设置包含 t 的时间表达式。打开现成模板可先看可播放的例子。

为什么模板对象的 X 位置不能直接修改？

模板中的运动点等对象由表达式或关键帧决定位置。点选对象后，右侧 X/Y 会显示当前值并标注控制来源；要改变运动方式，请修改下方「时间表达式」，或在时间线编辑关键帧。普通静态对象可直接修改 X/Y。

公式或图片为什么没有出现？

公式需要使用数学 TeX 写法，如 x^2+y^2=r^2；资源载入失败时先看底部状态栏的错误。图片建议通过「对象图层」添加图片并选择本地文件。

为什么导不出 MP4？

视频格式取决于浏览器的录制能力；编辑器会显示实际支持的格式。无法录制时，请使用「逐帧 ZIP」获取 PNG 序列。

关闭网页后项目还在吗？

当前版本不提供云端自动保存。请使用顶部「保存项目」下载 .cmanim 文件，下次通过「打开」导入。
