# 未来想做的事项

## 视频解说与配音

状态：待规划，首版不包含。当前视频导出只有画面，没有音轨。

- 支持为场景或时间线步骤编写解说词，并设置开始时间、时长与对应画面。
- 支持上传录音作为配音；后续评估文字转语音（TTS）生成解说。
- 预览时同步播放画面与解说，导出时将音频合入视频，并处理静音、音量和时长不一致的情况。
- 明确语音生成方案、浏览器兼容性、离线能力及导出格式后，再拆分具体开发任务。

关联：[需求文档 FR-18](./requirements.md) 中的后续音频轨能力。此项尚未实现，不能把当前导出的视频视为带解说的视频。

## 左右侧栏统一使用可折叠 Panel

状态：待实现。当前左右侧栏已有折叠入口，但尚未抽象为统一的 Panel 组件。

- 提供可复用的 Panel 组件，包含 `title` 标题区和 `content` 内容区，并支持展开、收起。
- 左侧图层栏和右侧设置栏都使用该组件，分别维护折叠状态；收起时为画布让出空间。
- 保留现有内容与交互，包括左侧模板、场景和对象图层，以及右侧“项目／场景”“对象属性”标签页；现有顶部侧栏开关应与 Panel 状态同步。
- 验收时检查标题区的折叠操作、键盘可操作性、状态反馈，以及展开后内容和编辑状态不丢失。
