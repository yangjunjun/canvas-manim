# 实现状态（2026-10-01）

当前代码是可运行的二维 MVP，并非 [需求文档](./requirements.md) 所定义的全部 P0 已验收版本。实现采用单包目录 `src/core`、`src/sdk.ts`、`src/App.vue`，与 [技术实现文档](./technical-design.md) 中建议的多包目录不同，但共享场景模型、求值器和 Canvas 渲染器的边界相同。

已实现：pnpm 工程、TypeScript SDK 与声明文件、Vue 可视化编辑器、三类模板、基础二维对象与坐标曲线、受限表达式、参数、关键帧、确定性时间求值、公式 SVG 缓存、图片资产、项目 ZIP/JSON 读写、PNG/逐帧 ZIP/浏览器视频导出。编辑器可编辑路径和多边形顶点、拖拽图层排序、设置可见性关键帧与导出时间段，并只读展示和往返保存项目扩展数据。播放器可报告单对象表达式或资源加载错误并继续绘制其他对象；SDK 挂载支持显示尺寸、初始参数和项目适配策略，并拒绝越界参数。FR-16 已实现画布锚点布局、路径跟随、同类对象匹配变形、确定性轨迹残影和三种可复用动画组合；FR-17 的链接快照可复现项目、场景、参数和时刻，链接片段上限为 32,000 个字符。核心测试和 Chromium 冒烟测试覆盖这些流程、模板交互、保存重载及输出。

尚未完成或仅部分完成：

- 编辑器还没有完整的图形控制柄或通用的可视化曲线/公式创作流程。路径顶点目前通过属性面板数值编辑，尚不能在画布上直接拖动。
- FR-16 的匹配变形限同类对象与可插值属性；复杂公式内部的匹配变换属于 FR-18 的后续评估范围。动画组合目前提供三个内置组合并生成可继续编辑的普通轨道，尚无用户自定义组合库。
- 当前 SDK 以类型化场景数据为主要创作 API，未提供独立的链式场景构建器或运行时回调扩展接口。
- 双向往返已有「编辑器 → 保存 → 编辑器」和「代码数据 → 编辑器修改 → SDK 求值」的 Chromium 用例，错误恢复也有核心与浏览器用例；尚未完成所有共同能力的逐项往返覆盖和完整的屏幕阅读器验收。键盘用例覆盖播放、进度、参数、图层选择与属性编辑，同页双播放器的时间、参数隔离与销毁已有 Chromium 冒烟覆盖。
- 本地构建产物在 Chromium 中完成了模板、编辑、保存与输出冒烟，未发出外部资源请求；尚未做断开网络后的实际系统级验收。Firefox 155.0 的开发服务版本已通过同一套完整冒烟；WebKit 与实际 macOS Safari 尚未验收。视频编码依浏览器能力而定，不保证统一 MP4 或逐帧无丢帧。
- 尚未实现旧版本项目迁移；当前只接受 `schemaVersion: 1`。导入 ZIP 设置条目、总大小上限，但不能把本地文件导入当作不可信内容的完整安全审计。

因此，不应将 `pnpm build` 和现有测试通过等同于需求文档第 6 节的首版完成标准。

## 本机性能记录

2026-10-01 使用 `pnpm test:performance` 测量：Ubuntu 22.04.5（WSL / Microsoft Hypervisor）、Intel Core i7-1260P、Headless Chrome 151.0.0.0，设备像素比 1。脚本创建 1280×720 场景和 100 个带 `sin(t)` 位置表达式的圆形对象，连续播放 30 秒，以播放器每次 `onChange` 的时间间隔采样。新增 FR-16 求值后复测结果为 1801 帧、平均 60.03 fps、帧间隔第 95 百分位 17 ms、超过 50 ms 的间隔 0 个，JS 堆变化约 -0.11 MB。该结果达到本机 30 fps 目标，但不能替代技术设计中基准机和其他浏览器的验收。
