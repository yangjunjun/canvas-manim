# 实现状态（2026-09-30）

当前代码是可运行的二维 MVP，并非 [需求文档](./requirements.md) 所定义的全部 P0 已验收版本。实现采用单包目录 `src/core`、`src/sdk.ts`、`src/App.vue`，与 [技术实现文档](./technical-design.md) 中建议的多包目录不同，但共享场景模型、求值器和 Canvas 渲染器的边界相同。

已实现：pnpm 工程、TypeScript SDK 与声明文件、Vue 可视化编辑器、三类模板、基础二维对象与坐标曲线、受限表达式、参数、关键帧、确定性时间求值、公式 SVG 缓存、图片资产、项目 ZIP/JSON 读写、PNG/逐帧 ZIP/浏览器视频导出。核心测试和 Chromium 冒烟测试覆盖模板交互、保存重载及输出。

尚未完成或仅部分完成：

- 编辑器没有完整的图形控制柄、路径点编辑、图层拖拽排序和通用的可视化曲线/公式创作流程；可序列化扩展数据会保存，但没有专门的只读展示界面。
- 当前 SDK 以类型化场景数据为主要创作 API，未提供独立的链式场景构建器或运行时回调扩展接口。
- 尚未完成需求所述的双向往返全覆盖测试、失败资源恢复测试和完整的键盘/屏幕阅读器验收；同页双播放器的时间、参数隔离与销毁已有 Chromium 冒烟覆盖。
- 仅在本机 Chromium 做过真实浏览器冒烟；Firefox、Safari、离线部署、100 对象/30 秒性能基准尚未验收。视频编码依浏览器能力而定，不保证统一 MP4 或逐帧无丢帧。
- 尚未实现旧版本项目迁移；当前只接受 `schemaVersion: 1`。导入 ZIP 设置条目、总大小上限，但不能把本地文件导入当作不可信内容的完整安全审计。

因此，不应将 `pnpm build` 和现有测试通过等同于需求文档第 6 节的首版完成标准。
